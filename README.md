# gpt-tex-simbol-input

ChatGPTの入力欄でTeXコマンドを記号に変換し、数式のプレビューや回答・数式のブックマークができるChrome／Edge用拡張機能です。

> **GPTによる作成**：この拡張機能の独自コードとドキュメントは、ユーザーの指示に基づき、OpenAIのGPT（ChatGPT／Codex）が生成したものです。同梱するKaTeXは第三者が開発したライブラリです。

**現在のバージョン: 1.2.2** · **MIT License** · **APIキー不要**

## できること

| 機能 | 例 |
|---|---|
| コマンド＋Spaceで記号に変換 | `\alpha` → α、`\tau` → τ、`\neq` → ≠ |
| 分数・根号・添字をプレビュー | `\frac{a}{b}`、`\sqrt{x^2+y^2}`、`x_i^2` |
| 行列・複数行の式をプレビュー | `pmatrix`、`aligned` など |
| 文章に含まれる数式を表示 | `この式 $\frac{a}{b}$ を説明して` |
| 回答・数式をブックマーク | 名前を付けて保存、検索、数式プレビュー、TeXのコピー |
| 保存内容を管理 | 名前の変更、削除、元の会話へ移動、JSONでバックアップ・復元 |
| 機能を個別に切り替え | 記号変換とプレビューを独立してオン／オフ |

169種類の記号コマンドに対応しています。拡張機能のアイコンを押すと、対応コマンドを検索できます。

## インストール

Chrome／Edge **109以降**が対象です。ビルドやNode.jsのインストールは不要です。

1. このページ上部の **Code → Download ZIP** からダウンロードします。
2. ZIPを右クリックして「すべて展開」します。
3. Chromeのアドレス欄で `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開された **`manifest.json` が入っているフォルダー**（通常は `gpt-tex-simbol-input-main`）を選択します。
6. 開いているChatGPTのページを再読み込みします。

Edgeでは手順3を `edge://extensions` に読み替えてください。読み込んだフォルダーは、導入後も削除・移動せず保管してください。

## 使い方

### 記号に変換する

英数入力で `\alpha` と入力し、Spaceを押すと `α` に変わります。

- 変換に使ったSpaceは空白として入りません。空白も必要なら、もう一度Spaceを押します。
- **Shift＋Space**なら、変換せずに通常の空白を入力します。
- 日本語IMEで変換中、文字列選択中、未対応コマンドの場合は、記号変換しません。
- 大文字・小文字を区別します。`\gamma` → γ、`\Gamma` → Γです。
- Tab／Enterの動作は変更しません。

### 数式をプレビューする

数式だけを書く場合は、そのまま入力できます。

```tex
\frac{a}{b}
```

文章に混ぜる場合は、数式を `$…$` で囲みます。

```tex
この式 $\frac{a}{b}$ の意味を説明して
```

`$$…$$`、`\(…\)`、`\[…\]` にも対応します。行列や整列した式も入力できます。

```tex
\begin{pmatrix}a & b \\ c & d\end{pmatrix}
```

```tex
\begin{aligned}
D_u W &= 0 \\
D_\tau W &= 0
\end{aligned}
```

プレビューは入力欄の近くに表示され、入力に合わせて更新されます。入力途中でまだ解釈できない式は、文字列として表示されます。

**プレビューは入力内容を書き換えません。** 記号変換で置き換わった文字は、従来どおり実際の送信内容に反映されます。

### 表示を調整する

拡張機能のアイコンから、記号変換・プレビューそれぞれのオン／オフと、プレビュー範囲を設定できます。

| 表示範囲 | 動作 |
|---|---|
| 自動（初期設定） | 区切り付きの式、または数式らしい入力全体を表示 |
| 入力全体を数式として表示 | 区切りのない `x` なども数式として表示 |
| 区切り付きの数式のみ | `$…$` などで明示した部分だけを数式として表示 |

プレビューの「−」で折りたたみ、「×」でオフにできます。再開するには拡張機能の設定を開いてください。

### 回答・数式をブックマークする

1. ChatGPTの回答の下にある **「☆ 回答を保存」** または **「数式を保存」** を押します。
2. 数式の場合は、数式の選択一覧を開きます。各式にカーソルを重ねると、横にプレビューが表示されます。クリックで保存したい式を選びます。
3. 名前を付けて **「保存」** を押します。
4. 回答下の **「一覧」**、または拡張アイコンの **「回答・数式のブックマークを開く」** で一覧を開きます。

一覧でカーソルを重ねただけでは、保存対象や入力済みの名前は変わりません。キーボードでは↑↓・Home・Endでプレビュー、Enter／Spaceで選択、Escapeで選択を変えずに一覧を閉じられます。幅の狭い画面ではプレビューを一覧の下に表示します。

**回答下にボタンが出ない画面（Work画面など）**では、読み込み済みのTeX数式があると、画面右下に **「数式を保存（件数）」** と **「一覧」** が表示されます。そこから式を選び、名前を付けて保存できます。右下のボタンの対象はページ内の読み込み済みの式全体で、同じ式はまとめます。入力欄・コード例・拡張自身のプレビューは対象外です。回答の区切りが判別できない画面では、回答全体の保存には対応しません。

一覧では、名前・本文・TeX・会話タイトルの検索、回答／数式の絞り込み、コピー、名前の変更、削除ができます。数式は一覧でもプレビューできます。回答は本文をテキストとして保存し、取得できた数式をTeXの区切り付き原文として残します。画像・添付ファイル・元のレイアウトは保存しません。

**明示的に保存した内容だけを、ブラウザ内の `chrome.storage.local` に保存します。** 回答はボタンを押した時点の内容で、生成中に保存すると途中までになります。上限は回答10万文字、数式8,000文字です。ページにTeX原文が含まれない数式は個別保存できません。

「元の会話を開く」で保存元へ戻れます。回答のIDを取得できた場合は、ページに読み込まれた該当回答まで移動します。会話URLがないページではリンクを保存できません。削除された会話、閲覧権限がない会話、未読み込みの回答へは移動できない場合があります。

**「バックアップ」** はJSONをダウンロードし、**「復元」** で読み戻せます。同じIDの項目は上書きしません。復元ファイルは5 MB・2,000件までです。途中で容量不足になった場合は、復元済みの件数を表示します。拡張を削除すると保存内容も削除されるため、先にバックアップしてください。バックアップには回答・数式・会話URLが含まれます。

## 更新

1. 新しいZIPを展開し、中身を以前に読み込んだ拡張フォルダーへ上書きします。
2. `chrome://extensions`（Edgeは `edge://extensions`）で、この拡張の更新ボタン「↻」を押します。
3. ChatGPTのページを再読み込みします。

`git clone` して使っている場合は、`git pull` 後に手順2・3を行います。古い版と新しい版を同時に読み込まないでください。

以前の配布ZIPの `tex-symbol-input` フォルダーを使っている場合も、そのフォルダーへ新しいファイルを上書きすれば更新できます。

## 動作範囲・制限

- 対象サイトは `https://chatgpt.com/*` と `https://chat.openai.com/*` です。
- 対象はページ上の編集可能なテキスト欄です。既存の会話を一括変換する機能ではありません。
- 記号変換ではカーソル直前のコマンドだけを処理します。
- プレビューは **入力8,000文字・区切り付き数式40個まで**です。超過しても入力は切り捨てません。
- 自動判定では、Markdownのインラインコード・コードブロック内の数式をプレビューしません。
- 数式描画は同梱のKaTeXとブラウザ標準のMathMLを使います。OSの数式フォントによって見た目は多少変わります。
- 任意のLaTeXパッケージや文書全体のコンパイルには対応しません。
- OpenAI公式の拡張機能ではありません。ChatGPTの画面更新や他の拡張との組み合わせにより、調整が必要になる場合があります。

## 安全性・データの扱い

記号変換・プレビューで扱う入力内容は保存しません。ブックマークでは、自分で保存した回答・数式・名前・日時・会話のURL／タイトル／回答IDをブラウザ内に保存します。クラウド同期や独自サーバーへの送信はありません。同じブラウザプロファイルの利用者は保存内容を閲覧できます。ChatGPTのアカウントごとの分離は行いません。

描画ライブラリは同梱しており、実行時に外部CDNから取得しません。保存内容はテキストとして表示し、数式描画には `trust: false` の制限を適用します。

ただし、対象サイトで実行する拡張なので、権限上はページの内容を読み書きできます。ストア審査や第三者による安全性監査は受けていません。詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## 開発・検証

実行用ファイルはリポジトリ直下にあり、ビルド不要です。

| 場所 | 内容 |
|---|---|
| `manifest.json` | 拡張機能の設定・バージョン |
| `background.js` | 回答下の「一覧」から拡張内の一覧ページを開く処理 |
| `content.js` / `symbols.js` | 記号変換・対応コマンド |
| `preview.js` / `preview-core.js` | プレビュー表示・数式の抽出 |
| `bookmarks-content.js` / `bookmarks-core.js` | 回答の保存ボタン・抽出・ローカル保存 |
| `bookmarks.html` / `bookmarks.css` / `bookmarks.js` | ブックマーク一覧・検索・バックアップ |
| `popup.html` / `popup.css` / `popup.js` | 設定・コマンド一覧 |
| `vendor/katex/` | 同梱KaTeX・第三者ライセンス |
| `tests/` | 変換・描画・ブラウザのテスト |
| `scripts/package.py` | 配布用ZIPの作成 |

Node.js 20以降で基本テストを実行できます。追加パッケージは不要です。

```bash
node tests/verify.cjs
node tests/preview.cjs
```

実際のブラウザでの入力・表示のテストにはPlaywrightを使います。

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser.cjs
node tests/bookmarks.cjs
```

独自のChromiumを使う場合は、環境変数 `TEX_BROWSER_EXECUTABLE` に実行ファイルのパスを指定してください。

Python 3.9以降で配布用ZIPを作成できます。

```bash
python scripts/package.py
```

`dist/tex-symbol-input-v1.2.2.zip` のように、manifestのバージョンに対応するZIPを生成します。

Chromium 153のテスト用ページで文字入力・数式表示・個別設定と、ブックマークの保存・検索・コピー・削除・復元を確認しています。ブックマークのブラウザテストでは拡張APIを模擬しています。利用中のChatGPT画面そのものでの互換性は未確認で、画面構造の変更により保存ボタンが出なくなる場合があります。

v1.2.1では、回答の目印0件・TeX数式8件の画面をChromium 153で再現し、右下のボタン表示、式の選択・保存・一覧・元の式への移動、コード例と入力欄の除外、連続更新中の検出、ボタンの再設置を確認しています。実際のユーザーのWork画面そのものは未検証です。
